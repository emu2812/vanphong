3. PDF, OCR và chụp ảnh tạo PDF

Giới hạn cần đọc kỹ: Chú thích (tô sáng, ghi chú, vẽ tay) chỉ lưu kèm tên file trong trình duyệt, KHÔNG ghi đè vào ruột file PDF gốc. Muốn giữ file gốc nguyên vẹn thì tải file gốc về; muốn giữ chú thích thì mở lại đúng file đó trong trang này.
PDF cần mạng lần đầu: xem PDF dùng pdf.js qua CDN. Nếu mất mạng, trang sẽ báo rõ “không tải được pdf.js, kiểm tra mạng rồi thử lại” chứ không hiện trang trắng khó hiểu.
Chưa mở file nào

3a. OCR — nhận dạng chữ thành văn bản sửa được

OCR ưu tiên Tesseract.js qua CDN, chạy ngay trong trình duyệt, nhận dạng vie+eng (tiếng Việt có dấu + tiếng Anh). Cần mạng lần đầu để tải script và dữ liệu vie+eng; lần sau trình duyệt có thể dùng bản đã lưu trong bộ nhớ đệm. Nếu Tesseract.js không chạy được, dùng phương án dự phòng OCR.space qua mạng (language vie) — cần Bùi tự tạo key miễn phí ở ocr.space rồi nhập ở Cài đặt; trang không nhúng key trả phí nào. Bản miễn phí của OCR.space giới hạn số lần gọi/ngày và kích thước file. Không bịa kết quả OCR: nhận dạng lỗi thì Bùi sửa tay trực tiếp trong ô kết quả.

3b. Chụp ảnh tạo PDF thật

Chụp bằng camera (getUserMedia) hoặc nút chọn ảnh của điện thoại (input capture — cách ổn định nhất trên điện thoại). Tạo PDF bằng JavaScript thuần, tự viết mã nhúng ảnh JPEG, không cần thư viện, chạy ngoại tuyến sau khi đã chụp xong. PDF tạo xong được lưu vào danh sách file để đồng bộ, và mở được bằng chế độ OCR ở mục 3a.

5. Quản lý file

Danh sách tài liệu của web (lưu ở máy). Trạng thái từng file hiện ngay tại đây: Đã lưu máy / Chờ đồng bộ / Đã lên Drive / Đã lên OneDrive. Trạng thái Drive/OneDrive chỉ chuyển thành “đã lên” khi đồng bộ qua API thật sự thành công.

Tải file từ Drive / OneDrive về mở lại (ngay trong trang này)

Đăng nhập & Đồng bộ — ngay trong trang này

Đăng nhập Google và Microsoft nằm ngay trong trang web “Văn phòng của Bùi” này, không phải app khác, không làm riêng bên ngoài. Đăng nhập xong, Bùi bấm “Lên Drive” / “Lên OneDrive” ở danh sách file (mục Quản lý file) hoặc ngay dưới đây, và tải file về mở lại cũng ngay trong trang này.

Chưa đăng nhập.

Đồng bộ file đang chọn

Nguyên tắc: file luôn lưu ở máy trước. Có tài khoản và có mạng mới đồng bộ. Chưa đăng nhập mà bấm đồng bộ → file chuyển sang “Chờ đồng bộ”, đăng nhập xong bấm lại là lên.

Hướng dẫn tự đăng ký app OAuth (Bùi tự làm, không cần đưa key cho ai): Huong_dan_OAuth_Google_Microsoft.md — bản hướng dẫn ngắn viết riêng cho bản web này.

Cài đặt

KHÔNG bịa Client ID. Trang không có sẵn Client ID nào. Bùi tự đăng ký app OAuth (xem hướng dẫn ở mục Đăng nhập & Đồng bộ), rồi nhập Client ID vào đây. Chưa nhập thì nút đăng nhập sẽ báo rõ cần làm bước đó trước.

Kiểm chứng font tiếng Việt

Đoạn kiểm chứng — bấm từng nút để đổi font, xem dấu có vỡ không. Font mặc định là Carlito (metric tương đương Calibri, nhúng nội bộ từ bản 1.4, đủ dấu tiếng Việt). 5 font còn lại chỉ là tên font dự phòng trên máy người dùng, không tải từ mạng.

Tiếng Việt có dấu: à á ả ã ạ, ồ ộ ổ, ứ ự ử, đ, ê, ơ, ư — Bác sĩ Nguyễn Văn Đô đi học ở Hà Nội

Cách kiểm chứng: (1) file Carlito nhúng nội bộ (fonts/Carlito-*.ttf, giấy phép OFL) chứa đủ khối vietnamese U+1EA0–1EF9 cùng các khối Latin mở rộng; (2) đoạn trên chứa đủ thanh dấu, nguyên âm đôi và chữ đ. Bước nhìn bằng mắt cuối cùng vẫn cần Bùi kiểm tra trên máy thật.

Phần nào cần mạng, phần nào chạy ngoại tuyến

  • Ngoại tuyến: soạn thảo, bảng tính, trình chiếu, lưu/mở lại, xuất txt/docx/csv/xlsx/pptx, chú thích PDF đã tải pdf.js, chụp ảnh tạo PDF (sau khi chụp xong).
  • Cần mạng: tải pdf.js lần đầu, tải Tesseract.js + dữ liệu vie+eng lần đầu, dịch MyMemory, đăng nhập và đồng bộ Drive/OneDrive. Font Carlito nhúng nội bộ nên không cần mạng từ bản 1.4.
